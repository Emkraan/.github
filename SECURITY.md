# Security Policy

This is the default security policy for the **Emkraan** organization. It applies to
every repository that does not ship its own `SECURITY.md`.

## Reporting a Vulnerability

Report security vulnerabilities **privately**, never in a public issue, discussion, or
pull request. Open the affected repository's **Security** tab and use **Report a
vulnerability** (GitHub private vulnerability reporting / security advisories), which is
enabled across the organization.

If you cannot use that form, email the maintainer at the address on the repository owner's
GitHub profile.

Please do not include exploit details anywhere public until a fix or mitigation has shipped.
We aim to acknowledge a report within 72 hours and to release a fix or mitigation as soon
as practical, then credit the reporter unless anonymity is requested.

## Supported Versions

For each project, the latest release on the default branch is supported. Older tagged
releases are best-effort.

## Scope

In scope: the source in Emkraan repositories and the artifacts built from it. Out of scope:
third-party dependencies (report those upstream), and denial-of-service or social-engineering
findings against hosted instances.
